# J.A.R.V.I.S. - Desktop System Monitor & Overlay

Egy Python és PyQt alapú, interaktív asztali overlay alkalmazás. A projekt valós idejű rendszer-teljesítménymutatókat (CPU, RAM stb.) jelenít meg egy letisztult felületen, kiegészítve gyors alkalmazásindító (launcher) funkciókkal.

## 🚀 Funkciók

* **Valós idejű monitorozás:** Rendszererőforrások (CPU, memória) folyamatos nyomon követése.
* **Alkalmazásindító:** Gyors és kényelmes hozzáférés a leggyakrabban használt programokhoz.
* **Interaktív Widgetek:** PyQt alapú, testreszabható asztali overlay felület.
* **Alacsony erőforrásigény:** Háttérben futó, optimalizált működés.

## 🛠️ Használt Technológiák

* **Nyelv:** Python 3
* **Keretrendszer:** PyQt (PyQt5 / PyQt6)
* **Rendszeradatok:** `psutil` (vagy a kódban használt egyéb könyvtár)
